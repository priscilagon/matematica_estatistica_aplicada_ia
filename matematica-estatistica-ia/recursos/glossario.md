# Glossário

| Termo | Significado |
|---|---|
| Amostra | Parte observada de uma população. |
| Amplitude | Diferença entre o maior e o menor valor. |
| Atípico (outlier) | Valor muito distante dos demais; precisa ser investigado, não é necessariamente erro. |
| Correlação | Medida da relação linear entre duas variáveis, entre −1 e +1. |
| Covariância | Medida de como duas variáveis variam juntas; depende da unidade. |
| Desvio-padrão | Raiz da variância; mede a dispersão na unidade original. |
| Escala de medição | Nominal, ordinal, intervalar ou razão: define as operações possíveis com a variável. |
| Erro-padrão | Desvio-padrão da média amostral (σ/√n). |
| Feature | Variável de entrada de um modelo. |
| Gradiente descendente | Método de otimização que corrige os parâmetros no sentido que reduz a loss. |
| Hipótese nula (H₀) | Afirmação de ausência de efeito ou diferença, que o teste tenta contrariar. |
| Intervalo de confiança | Faixa de valores plausíveis para um parâmetro, com nível de confiança estabelecido. |
| Loss (perda) | Número que mede o erro do modelo; treinar é minimizá-la. |
| Mediana | Valor central dos dados ordenados. |
| Moda | Valor mais frequente. |
| Normalização | Reescala para um intervalo fixo, em geral [0, 1]. |
| Overfitting | Ajuste excessivo aos dados de treino, com má generalização. |
| p-valor | Probabilidade de resultado tão extremo quanto o observado, se H₀ fosse verdadeira. |
| Padronização | Reescala para média 0 e desvio-padrão 1 (z-score). |
| População | Conjunto de todos os elementos de interesse. |
| Probabilidade condicional | Probabilidade de um evento dado que outro ocorreu. |
| Quartil | Valores que dividem os dados ordenados em quatro partes iguais. |
| Variável de confusão | Terceira variável que influencia as duas analisadas e cria associação aparente. |
| Variância | Média (ajustada) dos quadrados dos desvios em relação à média. |
| Viés de amostragem | Erro sistemático por uma amostra não representativa. |
