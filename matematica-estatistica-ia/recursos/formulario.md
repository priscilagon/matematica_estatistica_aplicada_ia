# Formulário

| Conceito | Fórmula |
|---|---|
| Frequência relativa | f_r = f ÷ n |
| Média | x̄ = Σxᵢ ÷ n |
| Mediana | valor central (n ímpar) ou média dos dois centrais (n par) |
| Amplitude | máx − mín |
| Soma dos quadrados (SQ) | Σ(xᵢ − x̄)² |
| Variância populacional | σ² = SQ ÷ N |
| Variância amostral | s² = SQ ÷ (n − 1) |
| Desvio-padrão | √variância |
| IQR e limites de Tukey | IQR = Q3 − Q1; limites = Q1 − 1,5·IQR e Q3 + 1,5·IQR |
| Normalização min-máx | x' = (x − mín) ÷ (máx − mín) |
| Padronização (z) | z = (x − média) ÷ desvio-padrão |
| Covariância | cov = Σ(xᵢ − x̄)(yᵢ − ȳ) ÷ (n − 1) |
| Correlação de Pearson | r = cov(X,Y) ÷ (s_x · s_y) |
| Regra da soma | P(A ou B) = P(A) + P(B) − P(A e B) |
| Complemento | P(não A) = 1 − P(A) |
| Condicional | P(A\|B) = P(A e B) ÷ P(B) |
| Independência | P(A e B) = P(A)·P(B) |
| Bayes | P(H\|E) = P(E\|H)·P(H) ÷ P(E) |
| Normal (padronização) | z = (x − μ) ÷ σ |
| Binomial | P(X=k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ; μ = n·p; σ = √(n·p·(1−p)) |
| Poisson | P(X=k) = e^(−λ)·λᵏ ÷ k! |
| Erro-padrão da média | σ ÷ √n  (ou s ÷ √n) |
| IC 95% da média | x̄ ± t·(s ÷ √n) |
| Produto escalar | a·b = Σ aᵢbᵢ |
| Modelo linear | ŷ = w·x + b |
| EQM (loss) | média de (ŷ − y)² |
| Gradiente descendente | w_novo = w − α·dL/dw |
